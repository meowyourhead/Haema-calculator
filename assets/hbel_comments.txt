# Format
#   [N]                 starts the comment with code N
#   comment: text       the comment exactly as it goes into LabWare (one per code)
#   groups: a, b        source-sheet filters: normal, hbf, thal, variant
#   remark: text        a remark from the sheet (repeatable)
#   example: ID         an example sample ID (repeatable). Real sample IDs are
#                       not kept here: they go in "6. HBEL\examples.txt"
#                       next to the exe (see src/hbel_custom.rs)
#   link: Label | URL   a link (repeatable)
#   reference: text     a literature reference (repeatable)
#   set: Name           starts a named set of criteria (code 12 has two)
#   sheet <Column>: text   the sheet's own wording, shown verbatim
#                       (columns: A2, F, Hgb, RBC indices, C window, S window,
#                        Fe, HbH inclusion body)
#   <row>: rule [(flags)]   a matching criterion; flags are assumed, key or
#                       both: (assumed), (key), (assumed, key)
#     hba2, hbf          ranges in %:  A..B   A..<B   >A..<B   >A   <B
#     peak               normal, split, degraded
#     hb                 normal, low, markedly-low
#     indices            normal, micro-hypo
#     film               target, sphero, sickle, poikilo
#     c, s               neg, present
#     hbh                not-detected, detected
#     hba1c              normal, high
#   A comma list means "any of". (assumed) = not in the sheet, implied by the
#   comment. (key) = must be entered and matched for the comment to fit.
#   [resources]         tab-wide links (only `link:` lines)
#   Lines starting with # are notes.
